隱私權政策

這一頁說明 ziangyou.tw 會收哪些資料、用在哪裡、保存多久、交給哪些服務處理，以及你可以怎麼查詢或要求刪除。

公開日：2026-10-18・最後更新：2026-10-18

一

誰負責這些資料

本網站由游子昂競選辦公室經營，資料的管理者是游子昂本人。有任何隱私問題，請透過網站的聯絡表單或 Facebook 粉絲專頁私訊聯絡。

二

網站會收哪些資料

1. 你自己填的表單

網站上的「聯絡我們」「陳情通報」表單使用 Google 表單，「加入我們」表單使用 monday.com 表單。你填的姓名、電話、email、陳情內容等，只用在聯絡你、處理你反映的問題、安排志工與支持活動。

不會出售，也不會提供給其他政黨、候選人或廠商。需要向政府機關反映時，只轉述問題內容；要附上你的姓名或聯絡方式，會先問過你。不填表單也可以瀏覽網站，只是我們就沒辦法回覆你或處理你反映的事。

2. 網站上的 AI 小幫手

  • 你輸入的問題會經由 Cloudflare 轉送給 Google 的 Gemini 模型產生回答。
  • 送出前，系統會先遮蔽身分證字號、手機、市話、email。請不要在對話裡輸入個人資料。
  • 小幫手使用的是 Gemini API 免費方案。依 Google 的使用條款，免費方案的輸入與回答可能被 Google 用來改善服務。
  • 對話紀錄（已遮蔽個資的問與答）會保存 30 天後自動刪除，用途是了解大家在問什麼、回頭補充網站內容。
  • 為了限制每人每小時的提問次數，系統會記錄你的 IP 經過雜湊處理後的代碼，不保存原始 IP。
  • 你的瀏覽器會暫存這次的對話內容，關掉分頁就清除。

3. Meta 像素（Facebook 廣告成效）

網站裝有 Meta 像素，會把「有人瀏覽了這個網頁」這類事件傳給 Meta，用來衡量 Facebook 廣告的效果。這部分由 Meta 依它的隱私權政策處理。你可以在 Facebook 的廣告偏好設定中關閉，或用瀏覽器封鎖第三方 Cookie。

4. 嵌入的外部服務

網站使用 GitHub Pages 架設，並載入 Google Fonts 字型、Facebook 粉專外掛。這些服務在你瀏覽時可能記錄你的 IP 與瀏覽器資訊，各依其隱私權政策處理。網站另有連到 YouTube、新聞網站的連結，點出去後適用對方網站的政策。

5. 政治獻金

捐款人資料依《政治獻金法》登載於收支帳簿，並依法申報監察院。網站每月公開的徵信表，捐款人姓名只在取得本人同意後才公開。

三

Google 帳戶資料的使用（Gmail 連接程式）

競選辦公室自建一支名為「Ziang Personal Gmail MCP」的程式，只用來連接游子昂本人的 Gmail 信箱，協助本人閱讀信件、整理陳情回覆、建立信件草稿。

  • 這支程式只供游子昂本人使用，不對外開放，也不會存取其他人的 Google 帳戶。
  • 只建立草稿，不會代為寄出信件；寄出一律由本人按下傳送。
  • 從 Google API 取得的資料，使用與傳輸遵守 Google API 服務使用者資料政策，包括其中的「有限使用」規定。
  • 信件內容只用於上述用途，不用於廣告，不出售，也不提供給第三方。
  • 信件整理會由本人電腦上執行的 AI 助理（Anthropic 的 Claude）協助處理，僅為本人提供上述功能。
  • 授權憑證存放在本人電腦上；本人可隨時在 Google 帳戶的「第三方存取權」頁面撤銷授權。
四

資料在哪裡處理

競選辦公室在台灣使用這些資料。不過上面提到的服務（Google、Cloudflare、Meta、GitHub、monday.com、Anthropic）的伺服器多在台灣以外，所以資料可能在境外傳輸、儲存與處理。

五

保存期間

AI 小幫手對話紀錄保存 30 天。表單資料在競選與後續服務選民需要的期間保存，不再需要時刪除。法律規定必須保存的資料，例如政治獻金收支紀錄，依法保存。

六

你的權利

依《個人資料保護法》第 3 條，你可以要求查詢、閱覽、複製、補充或更正你的資料，也可以要求停止蒐集、處理、利用或刪除。請透過聯絡表單或 Facebook 粉絲專頁私訊提出。依法必須保存的資料除外。

七

政策更新

網站新增或停用會收資料的功能時，會更新這一頁，並修改上方的「最後更新」日期。
