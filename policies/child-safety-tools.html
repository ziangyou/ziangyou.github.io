🧒 屏東好查・兒少安全

補習班、教練、教保、醫事人員裁罰查詢工具

孩子上補習班、學才藝、上學前教育機構前，這些資訊其實查得到——只是分散在不同機關網站，沒有人整理成一頁。我把7個查詢管道整理在這裡，都是可以交叉查證的公開系統，自己動手查最快。

最後更新：2026-09-14・逐一連結已實測可開啟

📌 這頁純粹是工具整理，方便家長與市民自己查證，不是我的政見主張。7個管道裡有6個是政府官方系統，1個（各運動種類不適任教練名單）是民間用官方公告資料彙整的查詢工具，已標明來源性質。
官方系統（6個）

政府查詢系統

  • 全國短期補習班資訊管理系統（教育部）——查補習班是否立案、負責人是誰，以及被廢止／註銷的補習班名單。
    → bsb.kh.edu.tw
  • 運動部・不適任教練資訊專區——官方公告，查詢涉及違法事件、被列為不適任的各運動種類教練。
    → sports.gov.tw/News/6295
  • 運動部・教練證照查詢系統——查詢教練是否持有合格證照（A/B/C級），與不適任名單互為補充查證。
    → sports.gov.tw/CoachDatas/6357
  • 兒少法違法事件裁罰名單（衛福部社家署）——查詢違反《兒童及少年福利與權益保障法》而遭裁罰的個人與機構。
    → crc.sfaa.gov.tw/ChildYoungLaw/Sanction
  • 醫事人員性別事件資訊專區（衛福部）——公開涉及性騷擾、性侵害等性別事件的醫事人員案件與裁判書。
    → ma.mohw.gov.tw
  • 全國教保資訊網・教保人員裁罰查詢（教育部）——彙整各縣市依《教保服務人員條例》公布姓名、違法對待幼兒的裁罰紀錄，全國適用。
    → ap.ece.moe.edu.tw
民間彙整工具（1個）

非官方，但資料來自官方公告

  • 各運動種類不適任教練名單——跨運動種類彙整的體育不適任教練查詢工具。這不是政府網站，是民間用運動部等官方公告資料做的彙整介面，方便一次查多種運動類別；建議與上方運動部官方系統交叉核對。
    → coach-case-tracker.thinkingpower-office.workers.dev
資料來源
  • 教育部全國短期補習班資訊管理系統、全國教保資訊網
  • 運動部不適任教練資訊專區、教練證照查詢系統
  • 衛生福利部社會及家庭署、醫事司
  • 各連結均為公開官方系統網址，2026-09-14 逐一實測可開啟
